What this page checked

For every listing: the event's signature, that the embedded proof verifies for that domain under that key, and that the domain's DNS still agrees. A listing that fails any of the three is not shown as a listing.

Nostr has no gatekeeper, so a listing claiming apple.com will exist. The event stays on the relays; this page only declines to show it, and the check is public so any client can apply it. Use the Unverified toggle to see what was hidden and why.

The flex board works the other way round: anyone can put any domain there by paying, and nothing is checked. Paying there buys attention; only a proof gets a domain listed here.
