Recover your escrow

This page rebuilds your escrow from one recovery string and signs a transaction that sweeps it back to you. It makes no network requests of any kind, so there is no server that could be switched off and nobody to ask for permission.

Your recovery string contains a private key. Anyone who reads it can spend this escrow. Do not paste it into a website, a chat, or a support ticket, including ours. This page works offline: disconnect first if you like, and check the network tab afterwards.

How to broadcast it. Paste the raw hex into any node or block explorer that accepts one: bitcoin-cli sendrawtransaction <hex>, mempool.space, or a friend's node. This page makes no network requests, so it cannot broadcast for you.

The timeout path needs the timelock to have elapsed. If a node replies non-BIP68-final, the escrow is not old enough yet. The transaction is already valid; it just cannot be mined before its time. Keep it and try again.
